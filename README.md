# Presentación Climate Week — GitHub Pages

Este paquete está preparado para GitHub Pages.

1. Sube `index.html` y `.nojekyll` a la raíz de la rama `main`.
2. En GitHub: Settings → Pages → Build and deployment → Deploy from a branch.
3. Selecciona `main` y `/(root)` y guarda.
4. La URL será: https://losyoguis.github.io/presentacion-climate-week/

Importante: el archivo de entrada debe llamarse exactamente `index.html` en minúsculas.
