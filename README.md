# Presentación Climate Week / Rocasol

Versión corregida para Google Sites y navegadores.

## Google Apps Script
1. Cree un proyecto en Apps Script.
2. Copie `Code.gs`.
3. Cree un archivo HTML llamado `Index` y copie el contenido de `Index.html`.
4. Configure `appsscript.json` con el contenido incluido.
5. Despliegue como Web App y use la URL `/exec` en Google Sites mediante **Insertar > Incorporar > URL**.

## GitHub Pages / navegador
Use `index.html` en la raíz del repositorio. Las imágenes están incrustadas dentro del HTML.
